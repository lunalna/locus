# Locus

Locus is a fork of the GeoGebra source (GWT web apps) packaged as a Tauri desktop and iPad app. Remote: `github.com/lunalna/locus`. Upstream GeoGebra is merged in from time to time.

## Hard rules

- Under no circumstances copy or merge icons, materials, translations, trademarked materials or other assets from GeoGebra into Locus. This also applies when merging upstream. Only GPL/EUPL licensed code can be reused.
- Do NOT mention GeoGebra anywhere user facing in the app (UI text, window titles, app names, HTML pages, icons, URLs, error messages). Internal code names like `org.geogebra.*` or `ggbApplet` are fine. The only exception is the About modal (`source/tauri/ui/src/settings/About.svelte` and `licenses.js`), which shows the attribution the GeoGebra license requires.
- Original GeoGebra assets are only loaded at runtime from a user-supplied resource pack (`./dev.sh official-pack`). Never bundle them.

## Layout

- `source/shared/` Java core shared by all apps. Most logic is in `common/` (`org.geogebra.common`: kernel, euclidian views, commands, menus).
- `source/web/` GWT web frontend.
  - `web/` main module. Java in `src/main/java/org/geogebra/web/` (`full/` is the full app UI), SCSS in `src/main/resources/scss/`, HTML templates in `src/main/resources/org/geogebra/web/resources/html/`.
  - `web/build.gradle.kts` defines the `desktop` task, the list of desktop apps (`desktopApps`) and `desktopHtml()`, which strips GeoGebra branding from the app pages.
  - GWT entry module for Locus: `org.geogebra.web.SuperWeb`.
- `source/tauri/` Tauri app (Rust), app id `xyz.lunalna.locus`.
  - `src/` Rust backend: windows, file handling, sessions, exam mode, resource packs and CSP (`resourcepack.rs`), AI assistant and MCP (`assistant.rs`, `mcp.rs`, `tools.rs`), iOS (`ios.rs`).
  - `src/plugins/` plugin host: manifests, Ed25519 signatures (`signature.rs`, trusted keys), plugin windows and views, the `plugin_*` commands (`api.rs`). Plugins live in their own repos (`~/coding/locus-plugin-template`, `~/coding/locus-overlay`).
  - `ui/` Svelte 5 + Vite + Tailwind + shadcn-svelte UI for the settings modal, assistant and plugin panels and command list, injected into the GWT pages. Uses pnpm.
  - `themes/` built-in themes (`theme.json`), `icons/` Locus icons and wordmarks, `fonts/` bundled fonts.
  - `gen/apple` is generated by `tauri ios init` and not committed.
- `doc/dev/` upstream developer notes (adding commands, tools, object types).
- `dist/` release output.

## Building

Everything goes through `./dev.sh`:

- `./dev.sh dev` GWT dev server (localhost:8888) and the desktop app with the Vite dev server (localhost:5173).
- `./dev.sh gwt` GWT dev server only. `./dev.sh app` desktop app against a running GWT server.
- `./dev.sh html` regenerate the dev server HTML pages.
- `./dev.sh web` production build: Vite build of `source/tauri/ui`, then `gradle :web:desktop` into `source/web/web/build/desktop`.
- `./dev.sh macos`, `./dev.sh windows`, `./dev.sh release` portable builds in `dist/`.
- `./dev.sh ios`, `./dev.sh ios-device <name>`, `./dev.sh ios-dev` iPad builds.

Gradle runs from `source/web` with the root `gradlew`.

## Gotchas

- After Java changes, the running GWT dev server may keep serving an old compile. Restart it and reload before judging a change.
- GWT swallows exceptions thrown from JS called by Java (for example `window.locusAssistant`), so a failure can show up as an empty panel with no error.
- The page CSP comes from `src/resourcepack.rs` and depends on the active resource pack. New external sources must be added there.
